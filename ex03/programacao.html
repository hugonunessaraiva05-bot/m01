Oficina de HTML ensina a estruturar páginas

Autor: Hugo Nunes · 6 de outubro de 2026 · Categoria: Programação

Estudantes praticam títulos, listas e elementos semânticos.

Uma oficina fictícia de programação Web desafia os participantes a construir uma página pessoal usando apenas HTML5.

Os exercícios mostram como header, main e footer ajudam a organizar o conteúdo e como as ligações unem páginas.

Cada participante termina com uma página que inclui um título, uma lista e uma ligação para outro ficheiro. No final, o grupo verifica se os nomes das ligações permitem perceber o destino antes de as abrir.

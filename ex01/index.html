Sobre mim

Chamo-me Hugo Nunes e frequento a Licenciatura em Informática. Este projeto reúne os exercícios do Módulo 01, dedicados à construção de páginas Web com HTML5.

Interesso-me pelo desenvolvimento de software e pela assistência informática. Ao longo dos exercícios, pratico a organização de textos, a navegação entre páginas e a criação de formulários com validação nativa do navegador.

Interesses e temas de aprendizagem

  • Programação Web: construir páginas com uma estrutura clara.
  • Desenvolvimento de software: explorar soluções para organizar informação e apoiar os utilizadores.
  • Acessibilidade digital: facilitar a navegação e a compreensão dos conteúdos.

Projeto desenvolvido para a Saraiva Tech

No âmbito deste módulo, desenvolvi um website em HTML5 para a empresa fictícia Saraiva Tech. O projeto apresenta a empresa, os serviços de reparação de computadores, instalação de software, limpeza interna, montagem e atualização de PCs.

Organizei cinco páginas com um menu comum, perguntas frequentes e um formulário demonstrativo de pedido de assistência. Este é um trabalho académico, sem envio real de pedidos.
